La suscripción se renueva sola al final de cada periodo (mes, trimestre o año, según el plan). Ponemos todo de nuestra parte para que las herramientas funcionen siempre, pero dependen de servicios que no controlamos: la Chrome Web Store, las webs sobre las que trabajan las extensiones y las API que usan. También podemos añadir, modificar o retirar herramientas; si retiramos una parte importante de lo que has pagado, te lo compensamos.
